2MEASURED on this 4-GPU box

MEASURED — nothing in this section is extrapolated. Batch size 1, one decode process per GPU, the other GPUs of this box busy decoding. Speedup = rd tokens per second ÷ base tokens per second on the same items, both decoded here; it is the raw ratio of two measurements made hours apart on a shared host, so it contains the host-speed drift of section 3. Accuracy is items correct, %; Δ is the paired difference rd − base on the same items with a 95% bootstrap interval. Passes per block and 30B expert loads per token (unique expert loads summed over layers ÷ generated tokens) do not depend on the machine; drafter forwards per token counts every SDAR-1.7B forward (first draft and re-drafts).
