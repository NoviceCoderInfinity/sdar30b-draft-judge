      Baseline. The base pipeline was decoded here under the same 4-GPU load as rd: every item of the benchmarks that have a full base run (HumanEval and MBPP so far, plus any marked base in Table 0), the first 12 items of the others. On this box it reproduces the Phase 1 records token for token (HumanEval 164/164, MBPP 257/257, 12/12 on each sampled set), with the same adapter 35805974 and 30B revision c351bbc, so the work is identical across boxes. The 12-item baselines are small: per-item speed varies a lot, and a 12-item pairing on HumanEval or MBPP would have been off by up to 13% against the full answer.

      Cost model. The Phase 2 cost model enters only the modelled 8-GPU wall times in section 6; no measured number on this page depends on it.

      Timing: per-item seconds are measured from before prefill to after the last forward with CUDA synchronized at both ends; no polling or sleeps are involved.
