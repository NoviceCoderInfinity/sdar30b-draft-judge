# Literature notes (2026-09-06) for the draft-conditioned MoE-dLLM design

Holy grail: use SDAR-1.7B-Chat-b32 (dense drafter; rev 2c83c05) outputs on SDAR-30B-A3B-Chat-b32 (MoE, rev c351bbc), block 32, to cut experts/forward and/or passes/block; training allowed.

## Steps (dLLM)
- dParallel (2509.26488, ICLR26): certainty-forcing distillation. Data = model's own trajectories (92k GSM8K/PRM12K/Numina, filtered correct). Loss = CE on masked tokens of the active block (50% mask; context blocks clean, future blocks masked) + beta*entropy-minimisation (T=0.5, beta=2) on masked tokens already predicted correctly. LoRA r32/128, lr 2e-5, bs 64, 3-6 epochs, 2xH100, ~10 h on 8xA5000. LLaDA-8B GSM8K 256->30 steps, 8.5x, 76.1%. No block-diffusion / MoE.
- Learn2PD (2509.25188): lightweight filter predicts "current prediction == final"; up to 22x with KV cache on LLaDA. Controller-style adapter.
- Speculative Correction (2608.02625, Aug 2026): small dLLM (LLaDA2.1-mini) drafts full response (block AR, 16 steps, thr .25), large (Flash) refines whole sequence bidirectionally in 4 passes (thr .20), TRAINING-FREE. GSM8K-384: mini .703, flash .848, mini->flash .752 at 1.37x; flash->flash .899 at 1.20x. Ablation: mask-only refinement at same budget .004 vs draft-init .899 => drafts give structure. Limits: distribution mismatch drafter/refiner; "trained or jointly optimized cascades" left as future work. CLOSEST PRIOR ART for the steps side; ours = trained, block-level, MoE, SDAR (whose loss never trains unmasked positions).
- ProSeCo (2602.11590): self-correction training with corruption = model's own argmax predictions; interleaved unmask/correct; GSM8K 77.5->82.2 on LLaDA-8B, 2-3x faster sampling. Corruption is self, not a small drafter.
- Corrective DLMs (2512.15596): mask + uniform-replacement corruption on visible tokens, CE on corrupted visible tokens (lambda_noise); confidence-based remask at inference.
- GIDD (2503.04482): hybrid mask+uniform noise unlocks self-correction.
- Remask-don't-replace / T2M (2604.18738), RemeDi, Spec-AUF (2607.01893: train block drafter under inference distribution; accept-until-fail; AR target), SimSD, DFlare, PSD (2605.15609), BlockPilot, APD (2506.00413: small AR model as mixture weight for dLLM parallel sampling; inverts spec decoding).

## Experts (MoE dLLM)
- DES (2602.00879): DES-Seq / DES-Vote coreset per forward; -55% unique experts, 99% accuracy, training-free.
- TEAM (2602.08404, code PKU-SEC-Lab/TEAM-MoE-dLLM, opencompass harness): DCD (delayed KV caching of decoded tokens, refresh-free), LAC (cold masked tokens route only within the "necessary set" from accepted+hot tokens), SEH (4 branches). SDAR-30B-A3B-b32, block 32, thr .95, A100: GSM8K vanilla 90.60 / TEAM 90.30; experts/step 59.11->36.20; tokens/step 3.16->4.79; experts/token 18.71->7.56; speedup 1.83x (avg 1.94x). Training-free. STRONGEST block-32 baseline on our exact model.
- dMoE (2605.30876): block-level routing: sum token router scores -> top-p coreset per block; tokens pick top-k within the coreset; ROUTERS trained by self-distillation (700k samples, LLaDA2.0-mini, 2 epochs). Unique experts 69.5->16.5 (4.2x), 99.55% retained, 1.36-2.04x; beats DES. No drafter. Trained coreset already exists => draft's expert-side value must be shown as (i) informed pass-1 coreset, (ii) fewer passes.
- EC-DLM (2604.01622): expert-choice routing + timestep-dependent capacity (training from scratch).
- REFLEX (2608.01784): refinement-aware compute allocation for MoE dLLMs (check).
- LLaDA-MoE / LLaDA2.0 / LLaDA MoE v2: MoE dLLM families.

## Draft model -> expert prediction (AR MoE, prefetch)
- SP-MoE (2510.10302): draft attention outputs through target gate, training-free, ~88% top-1 layer accuracy; prefetch only.
- SPICE (2608.21240): draft aligned to predict target expert accesses + low-rank expert surrogates for misses; 3-3.5 pt GSM8K loss.
- APEX, ExpertFlow, MoE-SpeQ, Fate (cross-layer gate), DraftExpert (self-spec MoE), MoESD.
None applies a draft to a diffusion block's 32 simultaneous positions, none trains the target to tolerate a draft-informed restriction.

## SDAR facts
- Training: block-wise ELBO, loss only on [MASK] positions (unmasked positions never supervised); linear schedule; SFT keeps prompt clean; 50B CPT + 4B SFT tokens from Qwen3-Base; LlamaFactory-based SFT framework released.
- Paper Table 2 (published SFT setting): 1.7B GSM8K 80.1, 30B-A3B 91.4.
- Decoding: dynamic threshold tau, >=1 token per step; b32 checkpoints trained for block 32.

## Added 2026-09-06 (after the probe)
- SimSD (2606.02544): SDAR-1.7B drafts for SDAR-8B at small block widths, training-free; paired data/mask layout with temporal-causal attention and RoPE index reuse; prefix speculative sampling alpha=min(1,p_t/p_d); 7.46x at B=4 (71.6 vs 9.6 tok/s), acc 0.713 vs 0.696. Closest training-free cousin. Not MoE, not block 32, prefix acceptance.
- PSD (2605.15609): self-drafting from cached predictions, per-position acceptance by target confidence (tau .9), block 32, 4-5.5x TPF on LLaDA-1.5/Dream/openPangu, training-free.
- Probe facts: stock SDAR-30B-b32 at filled slots predicts the NEXT token (90.4%); halves judge sycophantic (confirms 76% of wrong draft tokens); blind marginal acceptance gamma .5 => +4.7 slots/block at .963 precision.
