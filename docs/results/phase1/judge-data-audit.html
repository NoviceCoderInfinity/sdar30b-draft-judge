What stands out

  • Science and IF are used up (about 100% seen); maths is at 36%, code 30% and chat 40%, so most of the unused converted data is maths and code.
  • The 30B caps difficulty. Only correct answers are kept, and it fails 81% of olympiad maths, 81% of competitive code, 84% of free-form science and 83% of 3-constraint IF.
  • Hard code is almost absent: 334 competitive items (0.16M tokens) against 66,223 function-level items, and 0.05M of the 10.08M code tokens seen.
  • TACO: 12,898 problems in TACO-verified → 4,792 prompts after filters (function-call and multi-answer problems dropped) → 607 in wave A → 163 kept. The 30B solves 42% of EASY and 3–8% of HARD / VERY_HARD.
  • Wave B holds about 1.95M ungenerated prompts. Generating it is the main source of more data.
Definitions: “prompts on disk” counts both waves in data/c1b/prompt_lists. Generated, rejected and converted are wave A (logs/c1b/gen/waveA, logs/c1b/trainset/waveA/index.jsonl; the 1,000-item probe holdout is included in converted but not in the training split). Seen tokens use the trainer’s own token unit: each block state carries its item’s corpus tokens divided by its usable blocks.
