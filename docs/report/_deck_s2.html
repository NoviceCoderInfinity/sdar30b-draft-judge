Chapter II · the idea

Per slot, not per prefix

Be careful with the size of this advantage. Textbook speculative decoding assumes each slot is an independent coin, which at 56% gives an accepted prefix of about 2 tokens. Measured here it is not: agreement is one shared trajectory, and the run of identical tokens from the start of a block averages 13.1 slots (median 9). So per-slot buys roughly 18 of 32 against ~13, not against 2. The real edge is that it also takes the correct slots scattered after a divergence, which a prefix scheme cannot reach at any agreement rate.

The price of that freedom: a causal verifier is free and exact, because the big model's output at position i is already a judgement of i+1 made without seeing it. A bidirectional block model has no such position. There is no free verifier here.

The same block, marginal against conditional

The mechanism, working, on real data. Slots 7–16, where the draft is right at all ten: the stock marginal averages 0.21 and commits nothing; the trained judge averages 0.77 and clears 0.95 at several. Slots 17–31, where the draft is wrong at fourteen of fifteen: the judge stays unconfident, which is the correct behaviour. This block took 17 stock passes.

Chapter III · the obstacle

The stock model physically cannot read a filled slot

SDAR's training loss is computed only at masked slots — that is what masked diffusion means. The output logits at a slot that already holds a token were never touched by a single gradient step.

So what answers there? The base model underneath is Qwen3, an ordinary next-token predictor, and that behaviour survives untouched at exactly the positions diffusion training never visited.

Reading a filled slot returns a shifted copy of the input. Not a weak judgement, not a noisy one. A different function entirely. This one fact explains every earlier attempt on this branch to "show the model the draft and ask what it thinks".
