04

The obstacle: the stock model cannot read a filled slot

This is the finding the whole project turns on, and it is a property of how SDAR was trained, not a bug in our code.

SDAR's training loss is computed only at [MASK] positions. That is the standard masked-diffusion objective: corrupt some tokens to the absorbing [MASK] state, predict them back, score nothing else. It means that at a slot which already holds a token, the model's output logits were never supervised by a single gradient step in 50 billion tokens of continued training.

So what does come out of a filled slot? The base model underneath SDAR is Qwen3, an ordinary autoregressive next-token predictor, and that behaviour survives untouched at exactly the positions diffusion training never visited. We measured it directly by filling a block with the model's own final tokens and reading every slot:

block filled with the FINAL tokens, read at slot i: argmax = token at slot i+1 ... 93.6% (of slots that have a successor) argmax = token at slot i ... 10.0% block filled with the DRAFT tokens, read at slot i: argmax = draft token at i+1 ... 84.8%

Reading a filled slot on the stock model gives you a shifted copy of the input. It is not a judgement of anything. This single fact explains every earlier failed attempt on this branch to "show the model the draft and ask it what it thinks".

Three ways to ask, and what each one actually returns

Since we cannot read a filled slot, there are only three remaining ways to get an opinion about a draft token out of the frozen model. We probed all three on 87 items, 537 blocks, 15,782 slots.

The halves trick fails for an interesting reason. Keeping the judged slot masked puts it back in the trained regime, and confidence duly explodes: the share of slots clearing 0.95 rises from 0.26 to 0.90. But the model agrees with the draft at 92% of slots, and specifically confirms 76% of the drafter's wrong tokens at above 0.95, while correcting a wrong draft in only 1.2% of slots. It is not verifying; it is deferring.

The control that proves this is deference and not competence: fill the context with the model's own incoherent pass-1 guesses instead of the drafter's coherent block, and the confirmation rate collapses from 33.4% of slots to 6.6%. The stock model is a sycophantic verifier of any coherent context. It trusts fluency, not correctness. Decoding end to end this way gives 67.0% accuracy against a 95.0% baseline. Closed.

The conclusion that motivates training

The ability "judge whether this specific token belongs in this specific slot, given its neighbours" does not exist anywhere in the frozen model. No threshold, no voting scheme, no clever masking pattern can extract it, because there is nothing to extract. If we want that ability, we have to put it there.

05

The training-free baseline, and why it is hard to beat

The third readout — the model's own opinion of the draft, formed before it saw the draft — costs nothing and works. It is the baseline everything else must beat.

The big model's very first pass on a block is run anyway, with the block empty. From those same logits, read qi = the probability the model assigns to the drafter's token at slot i. This number is uncontaminated: the model never saw the draft. If it is above a threshold γ, take the drafter's token for that slot even though the model's own top-1 did not clear 0.95. Zero extra forward passes. I will call this the free rule.

At γ = 0.50 the rule takes about 4.7 extra slots per block and gets 0.43 of them wrong. That turns out to be free in practice, because a wrong token in a slot the block later contradicts is usually re-derived: end to end, accuracy is exactly unchanged, item for item, while passes fall 15%.
