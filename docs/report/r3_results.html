Abstract (ICLR 2027 draft)

A free general expert: calibrated draft-aligned decoding for mixture-of-experts diffusion language models

Anupam Rawat (IIT Bombay) et al. · draft abstract for ICLR 2027 · numbers as of 15 Sep 2026, 19:24 IST

Diffusion language models can in principle write many tokens per forward pass, yet in practice they commit only a few positions at a time, because each token is predicted while its neighbours are still masked and the model is rarely confident enough to commit. For mixture-of-experts diffusion models the usual remedy is a shared expert, a dense path every token can rely on, but a shared expert large enough to matter is a new, wide module that must be trained from scratch on a great deal of data. We observe that such a general expert already exists for free: a small dense model of the same family is fully trained, shares the tokenizer, and can fill an entire block in a handful of cheap steps. The large model then no longer has to guess every token from masks; it only has to judge a draft, keeping the tokens it trusts and overriding the rest.

Judging is a skill the frozen model lacks, so we add a small judge adapter (a 27M-parameter LoRA on the 128-expert SDAR-30B-A3B, drafted by its 1.7B dense sibling) and find that how it is trained matters more than how long. A judge trained to be certain commits eagerly but is wrong about one confident override in five, which is fatal for code. We instead train it to be calibrated, scoring the very confidence the decoder thresholds at inference, so that a token committed at 0.95 is right 95% of the time and the product of confidences across a parallel commit is a trustworthy estimate that the whole commit is correct. One epoch of this calibrated training turns the same weights into a judge that commits twice as many tokens per pass as the baseline model with more than 99% precision.

Combined with decode-time expert pooling, the general-expert judge cuts the 30B model's expert compute per generated token by 1.4–1.5× on HumanEval, MBPP, GSM8K and MATH-500, while matching the baseline on GSM8K and AIME and staying within a point of the released model on math and a few points on code, measured on the full benchmarks with paired confidence intervals. Because the drafter is an existing smaller dense model of the same family, used as released, and the judge is a small adapter, the method adds no new pretraining and can be attached to any mixture-of-experts diffusion model that has a smaller dense sibling. We release the adapter, every checkpoint, and per-question decode records for all baselines.

Keywords: masked diffusion language models, parallel decoding, speculative drafting, mixture of experts, calibration.
