## What this round was (20-hour plan, agreed 21 Oct, retired the same night)

Continue the 128M judge LoRA (26.7M parameters, q,k,v,o of 48 layers, experts and routers frozen) on training states
that look like what rd1 and rd2 show the judge, with the **Phase 4 drafter's** tokens in them. Labels, loss and
optimiser are unchanged. The drafter is not trained in this round.

### The three state kinds the judge trains on

Per block, T = vanilla's tokens, D0 = the Phase 4 drafter's first draft (teacher-forced), D1 = its re-draft of the
holes. The committed set at pass p is "vanilla had committed the slot before pass p" (vanilla's own order; the judge's
order is unknown without judge decodes). Among the uncommitted valid slots, tentative = D0 == T, hole = D0 != T.

| Kind | Share | Committed slots | Tentative slots | Holes | Mimics |
|---|---|---|---|---|---|
| K1 | 15% | none | all slots hold D0 | none | pass 1 (Phase 1's draft_pass1 state) |
| K2 | 25% | T | D0 | [MASK] | rd2's pass 2, before any re-draft |
| K3 | 60% | T | D0 | D1 | every rd1 pass after the first, rd2's odd passes |

Loss rows = tentative + holes, target = T, exactly as in Phase 1. Shares follow how often each pass type occurs in
the Phase 4 rd1/rd2 records (pass 1 ≈ 13% of judge passes). `code/judge_round/sampler_k3.py`, `--k-mix`.

### Two data steps, one path each

| Step | Tool | What |
|---|---|---|
| first drafts D0 | **SGLang** (`draft_sglang_items.py`, plugin StaticDraftTraced, merged drafter as model path) | per block: prefix = prompt + vanilla's earlier blocks, block masked, 8-step s8 fill; 32 tokens + confidences |
| re-drafts D1 | HF harness (`redraft_items.py`, 8 shards) | per block: sample p, show T at committed slots, mask tentative + holes, fill only the holes in ceil(holes/4) steps, **ban on** (never D0 at a hole); store D1 at holes |
| items | `swap_drafts.py --redrafts` | items get draft/draft_conf = D0 and new arrays redraft/redraft_conf/redraft_pass = D1 |

The SGLang environment is built by `code/judge_round/setup_sgl.sh` (Phase 1's recipe). SGLang never produces a
benchmark number and never trains.

### Gate and evaluation (harness only)

Gate on the Gate-3 quarter, rd1 + ban + loop guard, new judge, paired with Phase 4 on the same questions: pass ≥ 5%
fewer judge passes per block at accuracy within noise; kill < 2%. Full seven sets in rd1 and rd2 only on a pass.

### Drafter: not this round

Phase 4 measured +5.0 points of draft agreement on matched blocks → +0.2 points of pass-1 commits. Its re-draft
agreement on held-out holes stayed at 21% because its re-draft states used the wrong holes. A drafter round on K3-shaped
holes is the next experiment if this round's gate passes; it would need D0 and D1 regenerated afterwards (about 3 h).

### What is approximate, and the escalation

The committed sets are vanilla's, not the judge's: some training holes are slots the judge would already have
committed. The re-draft tokens and the hole shape are right. The exact version records real judge passes by running
the judge loop inside each block (about 54 box-hours per 52M-token regeneration on the batch-1 decoder) and is the
next rental if this round passes.
